# Общий каталог скинов Welly

Лаунчер читает этот файл при запуске (не чаще раза в 6 часов):

```
https://abibaokak.github.io/welly-launcher/skins/catalog.json
```

Формат:

```json
{
  "version": 1,
  "updatedAt": 1793193216653,
  "skins": [
    {
      "name": "nickname",
      "uuid": "необязательно, 32 hex-символа",
      "model": "steve",
      "url": "https://abibaokak.github.io/welly-launcher/skins/<файл>.png"
    }
  ]
}
```

Правила:

- `name` — ник, с которым игрок заходит в игру. Если `uuid` не указан, лаунчер
  считает оффлайн-UUID по нику (`OfflinePlayer:<nick>`).
- `url` — только `https://` и только обычный внешний адрес. Файл должен быть
  PNG 64×64 (Steve) или 64×64 с прозрачным оверлеем (Alex).
- Картинка кладётся в эту же папку, имя файла — SHA-256 от содержимого PNG,
  чтобы обновление скина не ломало кэш у игроков.
- Записи без валидной картинки пропускаются, остальные продолжают работать.

Как добавить скин: положи PNG в `skins/`, добавь запись в `catalog.json`,
обнови `updatedAt` (миллисекунды Unix) и закоммить. После публикации GitHub
Pages игроки получат каталог при следующем запуске лаунчера.
