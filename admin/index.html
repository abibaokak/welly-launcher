Панель управления лаунчером — теперь отдельным приложением

Один exe без Node.js и установки. Внутри — все настройки лаунчера, новости, ключи доступа, роли и журнал действий. Открывается в собственном окне, данные хранятся рядом с файлом.

  • Настройки, новости и режимы сервера для лаунчера — в одном месте
  • Одноразовые ключи доступа вместо открытой регистрации
  • Публикация launcher-config.json для живого обновления лаунчера

Как начать

1

Скачайте и запустите

Двойной клик по exe. Панель откроется в отдельном окне и создаст папку данных рядом с файлом.

2

Получите доступ

На пустой базе ключ первого владельца лежит в welly-admin-data/database/FIRST-RUN-KEY.txt.

3

Настройте лаунчер

Раздел «Лаунчер»: брендинг, сервер, новости, обновления. Кнопка «Опубликовать» пишет конфиг для сайта.

Что внутри

Настройки лаунчера

Название и слоган, ссылки, режимы сервера, значения по умолчанию, обслуживание и обновления.

Новости

Свои записи и внешние RSS-ленты, публикация, закрепление и предпросмотр «как в лаунчере».

Ключи доступа

Одноразовые ключи для владельца, разработчика и поддержки. Полный ключ показывается один раз.

Роли и права

Гибкая настройка прав по разделам: дашборд, пользователи, новости, ключи, лаунчер.

Журнал действий

Кто, что и когда менял — с IP и деталями. История входов и публикаций конфига.

Формат приложения

Одиночный exe: закрыли окно — панель завершилась. Повторный запуск открывает уже работающую.
