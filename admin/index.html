Вход в панель

Панель работает прямо на GitHub Pages и сохраняет настройки в репозиторий. Для входа нужен GitHub-токен с правом записи в abibaokak/welly-launcher.

Как получить токен
  1. Откройте github.com/settings/tokens/new (классический токен).
  2. Поставьте галочку repo и создайте токен.
  3. Скопируйте его и вставьте сюда. Токен хранится только в этом браузере.

Можно и fine-grained token: доступ только к репозиторию welly-launcher, разрешение Contents: Read and write.

Не входите с чужого компьютера и не включайте «Запомнить» на общих устройствах.

Настройки лаунчера

Всё, что вы сохраните здесь, попадёт в launcher-config.json на сайте. Лаунчеры подхватывают изменения автоматически — без переустановки.

GitHub Pages обновляет сайт после коммита обычно за 30–90 секунд. Если лаунчер ещё видит старые данные — подождите и нажмите «Перечитать».
