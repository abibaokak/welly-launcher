Как начать играть

Скачивание, первый запуск и подключение к серверу.

  1. 01 ⬇

    Скачай лаунчер

    Нажми «Скачать» — откроется последний релиз на GitHub, файл WellyLauncher-v1.0.0.exe. Сохрани его в удобную папку.

    К скачиванию →
  2. 02 🚀

    Запусти файл

    Открой WellyLauncher-v1.0.0.exe. Если Windows покажет SmartScreen — нажми «Подробнее» → «Выполнить в любом случае».

    Файл без платной цифровой подписи, поэтому Windows перестраховывается.
  3. 03 🎮

    Выбери ник и версию

    Введи ник или войди в Welly ID, выбери Minecraft и нажми «Играть на сервере». Клиент и Java скачаются сами.

    Первый запуск может занять несколько минут — это нормально.

Первый запуск

Что произойдёт дальше

☕
Java подберётся сама. Для выбранной версии Minecraft лаунчер скачает совместимую Java 8–25. Уже установленная Java тоже подойдёт, если она совместима.
📦
Загрузчики — по желанию. Fabric, Quilt, Forge, NeoForge и OptiFine ставятся из панели выбранной версии. Подробности — на странице «Загрузчики».
🗕
Лаунчер не помешает. Перед запуском игры окно свернётся в панель задач и вернётся, когда Minecraft закроется. Это можно отключить в настройках.
